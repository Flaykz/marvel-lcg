# Debug Guide

Add `&debug` parameter at the end of the URL

## Card debug menu

1. Right-click any card to open the debug menu

## Debug console

1. Press `~` key to open the debug console
1. Press `Alt` key to extend it to full rows
1. Type any command like `gain 03012` `discard c11` to execute it
2. Use `Up` / `Down` arrow keys to cycle through recently used commands
